Responsibility
This module implements the Asset Management component of the Municipal Financial Management System

Required asset Information
.Asset ID
.Asset Name
.Asset Type
.Purchase value
.Department
.Condition

Functions
addAsset()- Adds an asset array and validates required text fields and purchase value
displayAssets()- loops through the registered asset array and displays each asset
searchAsset()- performs a linear search using the Asset ID and displays the matching asset

Files
assets.h- asset structure, constant and fuction declarations
assets.c- asset management implementation in c
